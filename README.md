# FIAP Cloud Games

## 📝 Sobre o Projeto

O **FIAP Cloud Games** é um projeto de estudo e aprendizado prático desenvolvido como parte do curso **"Arquitetura de Sistemas .NET"** da **FIAP**. O objetivo principal da solução é demonstrar a aplicação de boas práticas de arquitetura de software, padrões de projeto, Domain-Driven Design (DDD), APIs RESTful com .NET 10, persistência de dados no Azure SQL com Entity Framework Core, testes automatizados e integração em nuvem.
